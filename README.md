## 规则

| | |
|---|---|
| **落子** | 每回合把一个 4×4 放到任意能完整放下的位置。不重叠、不越界，数量无限 |
| **判负** | 回合开始时，若你**没有任何一个合法落位**，你输，上一个成功落子者赢 |
| **移动** | 每放 2 个方块得 1 个 token（上限 3），可把一个**对手**的 4×4 搬到另一个能放下的空位 |
| **移动不能续命** | 移动之后若自己依然无处可落 —— **立即判负** |
| **后手补偿** | 后手开局多 1 个移动 token |

12×12 恰好能被 3×3 = 9 个 4×4 铺满。纯平铺时先手放第 9 个即获胜 —— 所以「移动」不是锦上添花，它是后手**打破确定性**的唯一杠杆。

## 每回合要算的三件事

| | 问题 | 看什么 |
|---|---|---|
| **1** | 我还能往哪塞？ | 带绿色圆点的格子 = 方块左上角，状态栏有实时计数 |
| **2** | 我放下去，会砍掉多少自己的落点？ | 同一次落子往往同时废掉 4～16 个锚点 |
| **3** | 该不该花 token 挪对手？ | 挪它能给自己腾位，还是纯粹把对手钉死在坏位置 |

第 2 条最反直觉：**你每放一块，都在同时杀死自己的未来选项**。好的落法会让对手的可用锚点掉得比你快。

桌面鼠标 / 移动端触控都支持，不需要联网，没有构建步骤。

## 操作

- **鼠标所在格 = 方块的左上角**。带绿色描边与圆点的格子才放得下。
- 幽灵预览与真实落点**严格一致**：放不下的位置**不会**预览，看到就是能点。
- 点右侧 `移动 ×N` 进入移动模式 → 先点对手方块（金色虚线框），再点金色高亮的目标位。
- 没处可搬的对手方块会**置灰**；点非法位置会告诉你具体原因。
- <kbd>Esc</kbd> 取消当前移动操作。
- 顶部切「对战 AI / 双人热座」，支持**悔棋**（AI 模式下会一路退回你自己的回合）。

## 调参

改 `index.html` 顶部的 `CONFIG` 即可，这是全局唯一规则源：

```js
const CONFIG = {
  boardSize: 12,      // 棋盘边长
  piece: 4,           // 方块边长
  moveEvery: 2,       // 每放 N 个方块得 1 个移动 token
  moveMax: 3,         // token 上限
  secondStartMove: 1  // 后手补偿
};
```

| 参数 | 当前 | 建议范围 | 调高会怎样 |
|---|---|---|---|
| 棋盘 | 12×12 | 8～14 | 更久、更重策略 |
| 方块 | 4×4 | 3～5 | 更快封死 |
| 移动频率 | 每 2 个 1 token | 1～3 | 更多拉扯，更少平铺 |
| 移动上限 | 3 | 1～5 | 更多翻盘机会 |
| 后手补偿 | +1 | 0～2 | 更公平 / 更偏先手 |

校准目标：单局 3～8 分钟，先手胜率 40%～60%，后手胜率 40%～50%。

## 关于 AI

现在是一层贪心：对每个候选落位计算结果棋盘的**最大连通空域**，取最大者；无落位时才考虑移动，并跳过会导致自己无落位的自杀式走法。

它的问题是**不会主动进攻** —— 不会为了堵死对手的锚点而牺牲自己的空域完整性。想把它变成一个真正难缠的对手，见下面的路线图。

## 路线图

- [ ] AI 加入「对手剩余锚点数」差值评估，让它学会用移动主动堵人
- [ ] 把规则引擎抽成独立模块，配无浏览器冒烟测试（已有一版 node + DOM stub 的验证脚本）
- [ ] 落子/移动动画与音效反馈
- [ ] 可折叠调参面板（`CONFIG` 热更新）
- [ ] 真人试玩 20 局，校准移动频率与后手胜率
