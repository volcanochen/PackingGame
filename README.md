# PackingGame · 装箱对决（方块版）

两位玩家把无限多的 **4×4 方块** 轮流塞进同一块 **12×12** 棋盘，谁先放不下谁就输。
单文件 HTML，浏览器直接打开即玩，无依赖、无构建。

**远端仓库：** `git@github.com:volcanochen/PackingGame.git`
**当前版本：** r2.2 · ruleset `packing-duel-r2`

## 运行

```bash
# 方式 1：直接双击 index.html
# 方式 2：起个本地服务（推荐，避免个别浏览器的 file:// 限制）
python -m http.server 8000
# 然后打开 http://localhost:8000
```

## 玩法一句话

- 落一个 4×4 方块到任意能完整放下的位置（不重叠、不越界）
- **回合开始时若你没有任何合法落位，你判负** —— 上一个成功落子者获胜
- 每放 2 个方块得 1 个「移动」token（上限 3），可把一个**对手的方块**搬到另一个空位
- **移动不能续命**：移动执行后若自己仍无落位，立即判负
- 后手开局补偿 1 个移动 token

操作：鼠标所在格 = 方块**左上角**，带绿色描边与圆点的格子才放得下；幽灵预览与真实落点严格一致（所见即所得）。

## 调参

改 `index.html` 顶部的 `CONFIG` 即可：

```js
const CONFIG = {
  boardSize: 12,      // 棋盘 12×12
  piece: 4,           // 清一色 4×4
  moveEvery: 2,       // 每放 N 个得 1 个移动 token
  moveMax: 3,         // token 上限
  secondStartMove: 1  // 后手补偿
};
```

## 变更记录

| 版本 | 变化 |
|---|---|
| r2.2 | 幽灵预览改为所见即所得（锚点 = 鼠标格，放不下不预览）；合法锚点加圆点；移动模式金色目标预览 + 不可搬方块置灰；点击非法位置给出原因；修 AI 模式悔棋失效；状态栏显示可落锚点数 |
| r2.1 | 移动后仍无落位即判负；新增幽灵预览；AI 不再自杀式移动 |
| r2 | 改 12×12 + 清一色 4×4 + 放不下判负；唯一道具「移动」；后手补 1 token |
| r1 | 7×7 多变箱子库存（已废弃） |
