## 先看一个死局

下面这盘棋，**整块棋盘只剩 16 格空着**，可轮到的人**一个 4×4 都塞不进去**，直接判负：

> `██` 你　`▓▓` 对手　`□□` 还能落子的位置　`··` 空着，但塞不进 4×4

右侧上下各有一块空隙，**宽度刚好 4 格** —— 塞一个方块绰绰有余 —— **可它们都只有 2 行高**。

更扎心的是：就算这时候你手上还有移动 token，也搬不出任何能让自己落子的形状（游戏会在你动手之前就判负，不会让你白试）。

> **你争的不是「谁放得多」，而是「最后谁还有地方放」。**

## 规则

| | |
|---|---|
| **落子** | 每回合把一个 4×4 放到任意能完整放下的位置。不重叠、不越界，数量无限 |
| **移动＋落子** | 花 1 个 token 搬走对手的一个方块后，**同一回合内你还要再落一个 4×4**。连招每回合最多一次 |
| **获得 token** | 每放 2 个方块得 1 个（上限 3），后手开局多给 1 个 |
| **判负** | 轮到你时，既没有合法落位、也搬不出能落子的局面 —— 你输，上一个成功落子者赢 |
| **移动不能续命** | 移动只是重排对手的方块，造不出新空间。凑不出 4×4 就是死局 |

这就是「移动」真正的用法 —— 同一回合里**先清障、再占地**：

```text
你的回合  ──▶  直接落一个 4×4                  ──▶  回合结束
          └─▶  移动对手方块 ──▶ 再落一个 4×4   ──▶  回合结束
```

注意：**只有搬完之后你自己还有地方落的那些目标才是可选的**。搬完自己也堵死的走法根本不会出现在棋盘上 —— 你不会被引诱着走进陷阱。

12×12 恰好能被 3×3 = 9 个 4×4 铺满。纯平铺时先手放第 9 个即获胜 —— 所以「移动」不是锦上添花，它是后手**打破确定性**的唯一杠杆。

## 每回合要算的三件事

| | 问题 | 看什么 |
|---|---|---|
| **1** | 我还能往哪塞？ | 带绿色圆点的格子 = 方块左上角，状态栏有实时计数 |
| **2** | 我放下去，会砍掉多少自己的落点？ | 同一次落子往往同时废掉 4～16 个锚点 |
| **3** | 该不该花 token 挪对手？ | 关键是搬完之后你能立刻占住哪 —— 挪完自己也落不了的搬运毫无意义 |

第 2 条最反直觉：**你每放一块，都在同时杀死自己的未来选项**。好的落法会让对手的可用锚点掉得比你快。

## 操作

- **鼠标所在格 = 方块的左上角**。带绿色描边与圆点的格子才放得下。
- 幽灵预览与真实落点**严格一致**：放不下的位置**不会**预览，看到就是能点。
- 点右侧 `移动 ×N` 进入移动模式 → 先点对手方块（金色虚线框），再点金色高亮的目标位 → **搬完还得再落一个 4×4** 才轮到对手。
- 搬完之后你自己也堵死的那些目标是**不会**显示出来的，用不着担心点错。
- 没处可搬的对手方块会**置灰**；点非法位置会告诉你具体原因。
- <kbd>Esc</kbd> 取消当前移动操作。
- 顶部切「对战 AI / 双人热座」，支持**悔棋**（AI 模式下会一路退回你自己的回合）。

## 调参

改 `index.html` 顶部的 `CONFIG` 即可，这是全局唯一规则源：

```js
const CONFIG = {
  boardSize: 12,      // 棋盘边长
  piece: 4,           // 方块边长
  moveEvery: 2,       // 每放 N 个方块得 1 个移动 token
  moveMax: 3,         // token 上限
  secondStartMove: 1  // 后手补偿
};
```

| 参数 | 当前 | 建议范围 | 调高会怎样 |
|---|---|---|---|
| 棋盘 | 12×12 | 8～14 | 更久、更重策略 |
| 方块 | 4×4 | 3～5 | 更快封死 |
| 移动频率 | 每 2 个 1 token | 1～3 | 更多拉扯，更少平铺 |
| 移动上限 | 3 | 1～5 | 更多翻盘机会 |
| 后手补偿 | +1 | 0～2 | 更公平 / 更偏先手 |

校准目标：单局 3～8 分钟，先手胜率 40%～60%，后手胜率 40%～50%。

## 关于 AI

现在是**一层贪心 + 连招搜索**：评分 = `自己剩余可落锚点数 ×1000 + 最大连通空域`（前者才是真正的胜负判据）。每回合它会在两种打法里挑一个 —— 直接落子，或者「移动＋落子」；为了防止乱花 token，「连招」只有在收益明显高于机会成本（默认 6 格当量）时才会启用。

它目前**不会主动进攻** —— 不会为了堵死对手的锚点而牺牲自己的空间完整性。想让它变成真正难缠的对手，见下面的路线图。

## 版本

| 版本 | 关键变化 |
|---|---|
| **r2.3**（当前） | 「移动＋落子」同回合连招；自杀式搬运从可选目标里剔除；AI 比较两种打法并引入 token 机会成本 |
| r2.2 | 幽灵预览所见即所得（锚点 = 鼠标格，放不下不预览）；合法锚点圆点标记；悔棋修好 |
| r2.1 | 移动后仍无落位即判负；AI 不再自杀式移动 |
| r2 | 12×12 + 清一色 4×4 + 放不下判负；唯一道具「移动」 |
